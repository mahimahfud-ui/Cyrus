AI PROVIDER INTEGRATION
================================================================================

WHERE TO IMPLEMENT:
  File: public/provider-adapter.js
  
  Function 1: callGrok()
    - Called when user wants to use Grok from xAI
    - Requires backend endpoint: POST /api/ai/grok
    - Documentation included in comments

  Function 2: callChatGPT()
    - Called when user wants to use ChatGPT from OpenAI
    - Requires backend endpoint: POST /api/ai/chatgpt
    - Documentation included in comments

SECURITY:
  ✅ API keys NEVER in frontend code
  ✅ All API calls go through backend proxy
  ✅ Environment variables in .env file
  ✅ No secrets committed to git

HOW IT WORKS:
  1. User types message in Cyrus
  2. Message sent to provider-adapter.js
  3. Adapter routes to configured provider
  4. Frontend calls backend endpoint
  5. Backend calls actual AI API
  6. Response returned to Cyrus UI
